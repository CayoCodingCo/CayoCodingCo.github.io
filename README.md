# Cayo Coding Co — business site

Plain HTML/CSS/JS, no build tools. Same lightweight approach as the template-starter repo.

## Before going live

- **WhatsApp**: set to `+501 621-4804` (`wa.me/5016214804`) in three places — nav, hero, and contact section.
- **Email**: set to `cayocodingco@protonmail.com`.
- **Contact form**: wired to [Web3Forms](https://web3forms.com) with your access key already in place. Submissions land in `cayocodingco@protonmail.com`. Worth doing one real test submission after deploying to confirm it reaches your inbox.

## Deploying

1. Create a new repo under the CayoCodingCo org named `CayoCodingCo.github.io` (this exact name publishes automatically at the org's root domain).
2. Push these files to the `main` branch.
3. In repo Settings → Pages, confirm the source is `main` / root — usually automatic for this repo name.
4. Site will be live at `https://cayocodingco.github.io/`.

## Structure

- `index.html` — all page content and sections
- `styles.css` — design system (dark background, gold + teal accents)
- `script.js` — form handling placeholder
